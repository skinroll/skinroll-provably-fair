Algorithm

Public HashHMAC_SHA256(key = secret_salt, message = server_seed)
RollHMAC_SHA512(key = "<client_seed>-<nonce>", message = server_seed)
Numberint(first 15 hex chars of HMAC, 16) % 100000 + 1  →  1..100000
Same algorithm as the site's backend (PHP hash_hmac), verified against real records.

How to verify

  1. The site publishes hash = HMAC_SHA256(secret_salt, server_seed) before the seed is used.
  2. After you rotate your seed, the site reveals server_seed and secret_salt.
  3. Check that the revealed values hash to the published value (paste the salt above).
  4. For each bet, compute the roll from your client_seed, the server_seed and that bet's nonce.
  5. The roll decides win/lose inside the displayed range — nothing is server-side only.
